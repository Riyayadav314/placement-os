# 💼 Placement OS
### Student Placement & Career Assistance System

Placement OS is a desktop-based student placement and career assistance application built with Python and CustomTkinter.

The main goal of this project is to provide students with multiple placement-preparation tools in one application, such as resume building, resume analysis, quizzes, mock interviews, job recommendations, company eligibility checking, placement prediction, certificates and more.

---

## ✨ Features

### 👤 Student Profile
- View student profile
- Edit profile information
- Change account password
- Manage personal information

### 📄 Resume & Career
- Resume Builder
- Resume Analyzer
- Company Eligibility Checker
- Placement Prediction
- Job Recommendation

### 🎯 Placement Preparation
- Technical & aptitude Quiz
- Mock Interview practice
- Interview answer evaluation
- Interview preparation support

### 🏆 Progress & System
- Certificate generation
- Student Leaderboard
- Admin Panel
- About Project section

### 🔐 Security
- User login system
- Password protection
- Password update functionality
- Database-based student records
